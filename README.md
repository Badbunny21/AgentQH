AgentHQ

A dedicated home screen for your AI agents.

If you run an AI agent through Telegram, Discord, or anywhere else, you already know the problem: chat apps only ever show you the final result — never what your agent is actually doing while it works, what's still on its plate, or that it silently broke ten minutes ago. Its messages also get buried under everyone else's texts.

AgentHQ is a second front door into an agent you already own and run elsewhere. It never generates your agent's replies or thinks on its behalf — your agent's real backend keeps working exactly as it always has. AgentHQ just gives it a place to report status, progress, and errors in real time, and gives you a place to send it commands, all without touching a chat thread.

Core principle

AgentHQ never thinks for the agent. The agent's real intelligence always stays wherever it already runs. This keeps AgentHQ's costs flat (no AI usage bill on behalf of every user) and keeps the product honest — it's a window and a remote control, not a replacement brain.

Tech stack
Expo / React Native — one codebase, iOS + Android
Supabase — Postgres database, authentication, and serverless Edge Functions
